# 合并前检查清单

- [ ] 一个提交只解决一个可描述的问题；无关改动拆到独立提交。
- [ ] 改动解决明确需求；没有无关重构、重复实现或不必要依赖。
- [ ] 公开接口、输入输出、权限、错误行为和副作用均可解释。
- [ ] 新增或修改的可独立验收行为已登记唯一 ID，文档、代码路径和测试路径一致。
- [ ] 文档说明触发条件、边界、失败场景与验收行为，且未超过长度上限。
- [ ] 测试覆盖正常路径、关键边界与主要失败场景。
- [ ] 行为变更时旧测试与旧文档已同步更新；被移除的断言说明了废弃原因。
- [ ] 已运行相关测试、格式化、类型检查或静态检查，以及 `python scripts/check_docs.py`。
- [ ] 没有死代码、无效注释、遗留占位符、吞异常或泄露敏感信息。
- [ ] 交付说明列出改动、检查结果、未验证事项和风险。

任何一项不适用时，应在变更说明中写明原因；不得勾选未实际验证的项目。
