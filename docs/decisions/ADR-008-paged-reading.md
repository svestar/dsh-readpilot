# ADR-008：分页阅读采用 CSS 多栏与共享工具栏

- **状态：** accepted
- **日期：** 2026-11-03
- **范围：** FTR-002、FTR-009、FTR-010、FTR-019

## 背景

PDF 已有 Host 光栅页面与透明文本层，EPUB 用 iframe 保留原书 CSS，txt/md 用文本块渲染。各格式的阅读工具栏与翻页语义不同，缺少统一的单/双页阅读。需求是每种格式都能分页阅读，同时不引入前端构建或新的分页依赖，并保持选段、笔记与搜索可用。重排内容没有固定页，必须接受页数随布局变化。

## 决策

1. **重排内容用 CSS 多栏分页**。txt/md 在阅读框内层、EPUB 在 iframe 的 `html` 上应用 `column-count`、`column-gap`、`column-fill:auto`；单页一栏、双页两栏；翻页只改容器 `scrollLeft`，页数由视口宽与 `scrollWidth` 计算。这样不拆分 DOM，选区、笔记锚点与原书 CSS 仍有效。
2. **PDF 保持 Host 光栅页面，由 Client 组合双页**。Client 按布局请求一到两页 PNG，用 flex 并排；双页超宽时按可用宽度等比缩放整组页面，缩放按钮改变渲染 scale 后重新取图。文本层与现有页码/笔记逻辑不变。
3. **共享工具栏承载所有格式**。同一 `ReaderBar` 根据格式与模式显示上一页/下一页或上一章/下一章、位置、模式切换、布局切换，PDF 额外显示页码输入与缩放；避免多套工具栏各自演化。
4. **滚轮只在分页模式翻页**。监听目标分别是文本阅读框、EPUB iframe 文档与 PDF 视觉容器；累计到阈值才翻页，带 `ctrl`/`meta`/`alt` 的滚动不拦截。重排内容的章节边界交给章节切换，向后进入上一章时落到最后一页；PDF 到末页停止。
5. **默认保持原格式体验，状态不持久化**。打开书籍时 PDF 进入单页分页，EPUB/txt/md 进入滚动、单页布局；模式和布局只属于当前面板，不做跨书保存。
6. 分页计算集中在 `src/client/paging.ts` 的纯函数，文本、EPUB 与工具栏共用同一套栏宽/页数/边界规则。
7. **重排内容按 A4 页形排布**。滚动与单页分页时，用阅读区内容高度乘 `210 / 297` 得到页宽，夹取到可用宽度并水平居中，避免宽屏下单行过长；双页分页占满可用宽度。PDF 保留页面自身宽高比，单页按可用高度与宽度等比适配。容器或 iframe 尺寸变化时重算页宽，分页再按新页宽重测栏宽与页数。

## 备选方案

- DOM 切片或 JS 分页库：页边界更稳定，但需要拆分与重排 DOM，破坏选区、笔记锚点和原书样式，并引入依赖与构建成本。
- Client 端 PDF.js 查看器：双页、缩放更原生，但需要 worker 与数 MB 包体，违背当前单文件 Client 约束。
- EPUB CFI/epub.js 分页：页码与定位更精确，但需要 CFI 引擎，且难以与 iframe 原书 CSS 共存。
- 每个格式保留独立工具栏：改动小，但重复控件、交互分叉，无法满足统一阅读操作。

## 后果

收益：所有格式共用一套分页与工具栏；无新增运行时依赖或前端构建；文本选区、EPUB 原书样式与 PDF 文本层继续可用；重排页数自适应视口，单页保持稳定的 A4 比例与可读行宽。

代价：页数是浏览器布局结果，不稳定，无法作为 CFI 或印刷页码；EPUB 原书 CSS 可能干扰分栏；PDF 双页的笔记/高亮只覆盖第一页；模式与布局不跨书记忆；窗口或字号变化会改变总页数。单页页宽受容器高度约束，宽屏会横向留白，窗口高度变化会同时改变页宽与分页；双页与 PDF 不受 A4 页宽约束。PDF 单页受可用高度限制时，缩放只提高渲染分辨率，显示高度不变。

验证：`tests/paging.test.ts` 覆盖 A4 页宽、栏数与边界计算，Client 组装测试覆盖工具栏渲染；实际页宽、分栏几何，以及 PDF/EPUB 的翻页、缩放、选段与滚轮交互未在真实界面人工验证。
