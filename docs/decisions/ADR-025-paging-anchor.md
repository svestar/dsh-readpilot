# ADR-025：分页位置使用内容锚点与布局快照

- **状态：** accepted
- **日期：** 2026-11-21
- **范围：** FTR-019、FTR-033、FTR-053

## 背景

重排内容用 CSS 多栏分页，页数是浏览器布局结果，不是稳定的内容身份。译文逐块追加会改变 `scrollWidth`，同一章节在阅读过程中会从 3 页变成 5–6 页；字号、页宽、单双页和图片加载也会改变页数。把页码当作位置，会在布局变化时改变屏幕内容；跨章回翻落到“上一章最后一页”时，译文尚未加载，末页位置也不可知。

## 决策

1. **位置只用内容锚点表示**：章节 id + 块索引 + 块内高度比例，或显式的章首/章末锚点。页码是锚点在当前布局快照上的投影，不持久化。
2. **一次测量生成一份布局快照**：栏宽、栏距、步长、页数和每个块的栏片段矩形同时抓取；锚点与页码的换算走纯函数，翻页期间不再读 DOM。
3. **翻页规则按阅读顺序定义**：同章翻页是页 ± 1；末页继续向前落到下一章章首，首页向后落到上一章章末。章末锚点会一直保留，直到用户再次翻页；后续译文到达只重算页码，仍停在章末。
4. **布局输入变化先冻结再重算**：字号、页宽、单双页、译文节点集合变化时，先暂停翻页提交，测量完成后按锚点恢复；连续输入合并，不按旧页数跨章。
5. **译文是布局输入**：翻译批次按章应用，不按页丢弃；跨章回翻进入上一章时优先预翻译末尾若干块，让章末落点尽快稳定。
6. **进度比例由锚点派生**：`chapterFraction` 按块文本权重计算，译文开关不再改变同一位置的保存值；外部仍使用 0–1 的章节比例，进入分页器时按权重换成块锚点。

## 备选方案

- **整章翻译完成后再分页**：页数稳定，但首次进入要等待整章翻译，成本和延迟不可接受。
- **保留页码并在页数变化时夹取**：实现最小，但会把用户夹到新的末页，正是“下一页直接进下一章”的来源。
- **DOM 切片分页**：页边界稳定，但会破坏选区、笔记锚点和原书 CSS，违背 ADR-008 的约束。

## 后果

收益：译文、字号、页宽变化时屏幕上的首段内容不变；跨章往返可逆；阅读进度在译文开关前后落到同一内容。

代价：页码和总页数会随译文增长而变化，不能当作印刷页码；块内位置用高度比例近似，长段落跨页时可能有半页以内的误差；翻译到达后可能触发 1–2 次重排。

验证：`tests/page-anchor.test.ts` 覆盖翻页规则、章末跟随、双页映射与比例往返；FTR-019、FTR-033、FTR-053 记录可观察行为。
