# ADR-028：AGENTS 与阅读技能分层

- **状态：** accepted
- **日期：** 2026-11-27
- **范围：** FTR-017、FTR-022、FTR-023、FTR-060

## 背景

生成的 `AGENTS.md` 同时承载工具地图、阅读边界和笔记/记忆的详细流程。笔记与记忆规则只在相关任务中需要，却每轮都进入系统提示；这些规则还与 `reader_note`、`reader_notes`、`reader_memory` 的工具描述重复。DSH 会从用户级 `$DSH_HOME/skills` 发现 `SKILL.md`，skill catalog 只注入名称与描述，正文按需加载，适合承载低频流程。

## 决策

1. `AGENTS.md` 只保留每轮必须生效的内容：工具地图、书定位、逐字引用/找不到就说明、写入需明确请求、原则；笔记/记忆细则完全由技能承载，不在 AGENTS 重复技能名；简洁与不剧透属于默认角色风格，见 ADR-027。
2. 笔记与记忆的详细流程生成到 `$DSH_HOME/skills/dsh-readpilot-notes` 与 `dsh-readpilot-memory`，由 DSH 按需加载；用户级技能对所有工作区可见，匹配全局注册的阅读工具；工具参数语义仍以工具 schema 为准。
3. 技能只写插件独占目录；文件缺失时创建，已有管理标记时替换正文并补回缺失的 frontmatter，无标记的同名文件不覆盖。
4. 技能正文跟随书库语言；frontmatter 的 `name` 与双语描述保持稳定，避免语言切换导致 catalog 身份变化。
5. 技能同步与 `AGENTS.md` 同步共用状态加载和 `promptSync` 错误上报；没有书库时启动同步仍写入用户级技能，失败不阻塞书库。

## 备选方案

- 全部留在 `AGENTS.md`：每轮重复低频流程，继续与工具描述重复。
- 全部改成 skill：引用和写入边界若未加载就会失效，安全边界不能依赖懒加载。
- 只依赖工具描述：缺少跨工具的笔记类型选择、记忆开关与压缩流程。

## 后果

收益：常驻提示变短；笔记/记忆流程按需加载；AGENTS 与工具描述职责更清楚。
代价：多一套技能文件的生命周期（创建、语言切换、删除修复、frontmatter 补全、用户文件保护）；用户级技能会出现在所有工作区，需要新的会话验证后才会刷新 catalog。
