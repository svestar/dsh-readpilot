# ADR-026：本地化与工作区语言

- **状态：** accepted
- **日期：** 2026-11-25
- **范围：** FTR-017、FTR-021、FTR-023、FTR-024、FTR-036、FTR-042、FTR-049、FTR-053、FTR-056

## 背景

插件目前提供中文和英文两套界面文案，但英文 UI 仍会遇到中文的客户端错误、Host 错误、会话标题、内置提示词、翻译源名称、导出内容和 Agent 上下文。`AGENTS.md` 和阅读上下文由 Host 生成，Host 当前没有稳定的 UI 语言来源，也不适合在每次界面语言变化时重写书库文件。

需要把“界面语言”和“工作区语言”分开：界面语言跟随 DSH 当前 UI；工作区语言在书库首次初始化时确定，并用于该工作区生成的 Agent 文档和内容。

## 决策

1. **语言来源**
   - 界面语言跟随 DSH 当前 UI，只支持 `zh` 和 `en`；其他 UI 语言回退到 `en`。
   - 客户端在首次配置书库时把当前 UI 语言传给 Host；Host 不自行猜测 UI 语言。
   - 不增加独立的插件语言开关。

2. **工作区语言只初始化一次**
   - 工作区首次创建/初始化时捕获当前 UI 语言，作为 `workspaceLanguage`。
   - 已有工作区没有语言标记时按 `zh` 处理，避免升级后把既有中文工作区改成英文。
   - `AGENTS.md` 的管理块记录语言标记与内容版本；Host 以该标记为准，可在内存中缓存。
   - 之后切换 DSH UI 语言，不重写 `AGENTS.md` 的语言，也不改变工作区生成的 Agent 内容语言。
   - 换工作区、删除后重新初始化时，才按当时 UI 语言重新确定。

3. **内容版本与语言分离**
   - 插件升级仍更新 `AGENTS.md` 管理块的规则内容，但保留原 `workspaceLanguage`。
   - 管理块由插件维护，升级时可替换；管理块之外的用户内容保留。
   - 旧文件没有语言标记时，迁移时固定为 `zh`，不因当前 UI 语言重写。

4. **工作区语言管什么**
   - `AGENTS.md` 及阅读、笔记、记忆注入上下文。
   - 新建伴读会话的标题；旧会话标题不自动改名。
   - 未编辑的内置提示词；用户编辑过的内置提示词和自建提示词保留原文。
   - 导出文件名、导出标题与生成的分组/元数据；用户写的正文不翻译。
   - Agent 工具结果中的操作提示，保证同一工作区的 Agent 输出语言一致。

5. **界面语言管什么**
   - 按钮、菜单、对话框、帮助手册和空状态。
   - 客户端错误提示；Host 保留稳定错误码，客户端按当前 UI 映射。
   - 翻译源名称等由客户端展示的标签。

6. **内置提示词**
   - `presets.json` 继续是全局文件，不拆成每工作区一份。
   - 未编辑的内置提示词按工作区语言显示；需要持久化“是否被编辑”的标记，避免依赖标题或模板文本猜测。
   - 编辑过的内置提示词和自建提示词按用户内容处理，不自动翻译、不因切换工作区语言而改写。

7. **用户内容不翻译**
   - 书内文字、用户批注、长笔记、记忆和自定义提示词保持原文。
   - 语言切换只影响插件生成的界面与默认内容。

## 后果

收益：

- 已有中文工作区升级后行为稳定，不会因为用户切换 UI 语言而被改写。
- 界面语言和工作区语言边界明确；英文 UI 可以逐步补齐而不阻塞中文用户。
- `AGENTS.md` 内容升级和语言冻结解耦，便于维护提示词版本。

代价：

- DSH UI 语言与工作区语言可能不同；英文 UI 打开中文工作区时，界面是英文、Agent 文档和部分生成内容是中文。需要在帮助/使用说明中明确。
- Host 需要接收并保存语言，增加配置参数、迁移标记与错误码映射。
- 内置提示词需要维护“未编辑/已编辑”状态和两套默认文本。
- 大量 Host 错误需要从中文 message 迁移到稳定错误码；动态参数仍由客户端组织文案。

## 验证

- 已有中文工作区升级后 `AGENTS.md` 仍为中文，切换英文 UI 不改写。
- 新建英文工作区生成英文 `AGENTS.md`；新建中文工作区生成中文。
- 删除 `AGENTS.md` 或重新配置工作区后按当前 UI 重新初始化。
- 插件内容版本升级保留原工作区语言。
- 未编辑内置提示词随工作区语言显示；编辑过的提示词和自建提示词保持原文。
- 新会话标题、导出文件名/标题/元数据使用工作区语言；用户正文不变。
- Host 错误使用稳定错误码，英文/中文 UI 分别显示对应文案。
- 语言切换后 UI、帮助和错误跟随当前 UI，Agent 文档与生成内容保持工作区语言。
