# dsh-reader

DSH Web GUI 的电子书阅读插件。书库是一个用户指定的本机目录；配置后该目录会注册为独立的 DSH 工作区，每本书的伴读会话都保留在这个工作区里。

## 当前能力

- 书库：扫描配置目录中的 `.txt`、`.md`、`.epub`、`.pdf`；前两种可读，后两种列出但暂不能打开。
- 阅读：章节目录、上一章/下一章、字号调整、阅读进度保存。
- 伴读：阅读界面右侧有伴读栏，显示会话历史并可输入；宽度可拖动，用户消息右对齐、助手消息左对齐并支持基础 Markdown；窄屏下是可折叠抽屉；选中正文后的“解释 / 总结 / 翻译”只把引用和问题预填到输入框，不自动发送。
- 工具：`reader_books`、`reader_open`、`reader_read`、`reader_search`，供模型按需读取和引用，不会一次注入整本书。

## 安装与首次使用

通过 Plugins 页面选择本地目录安装，或使用 `plugin_manager` 的 `install_bundle` 指向本目录。安装后刷新页面，在左侧栏点“阅读”，输入或选择书库目录，点“创建书库”。

## 数据

书库原文件不复制。设置、进度、会话映射与解析缓存位于 `$DSH_HOME/dsh-reader/`；书籍解析缓存以路径生成的稳定 id 加文件修改时间失效。

## 限制

EPUB 与 PDF 解析、笔记、全文索引尚未实现；PDF 计划只做文本抽取与页锚点，扫描版不提供 OCR。单本书默认限制 100 MB，书库扫描深度 3 层、最多 2000 个文件。
