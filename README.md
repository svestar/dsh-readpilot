# dsh-reader

DSH Web GUI 的电子书阅读插件。书库是一个用户指定的本机目录；配置后该目录会注册为独立的 DSH 工作区，每本书的伴读会话都保留在这个工作区里。

## 当前能力

- 书库：扫描配置目录中的 `.txt`、`.md`、`.epub`、`.pdf`；四种格式均可读，EPUB 按 spine 抽文本，PDF 仅抽取文本层。
- 阅读：章节目录、上一章/下一章、字号调整、阅读进度保存；书内搜索可跳转到命中位置，笔记可建、列、删并跳回原文。
- 伴读：阅读界面右侧有伴读栏，显示会话历史并可输入；宽度可拖动，用户消息右对齐、助手消息左对齐并支持基础 Markdown；窄屏下是可折叠抽屉；选中正文后的“解释 / 总结 / 翻译”只把引用和问题预填到输入框，不自动发送。
- 工具：`reader_books`、`reader_open`、`reader_read`、`reader_search`、`reader_note`，供模型按需读取、检索和记笔记，不会一次注入整本书。

## 安装与首次使用

通过 Plugins 页面选择本地目录安装，或使用 `plugin_manager` 的 `install_bundle` 指向本目录。Host 端解析依赖 `jszip`、`linkedom`、`pdfjs-dist`，安装时会一并下载。安装后刷新页面，在左侧栏点“阅读”，输入或选择书库目录，点“创建书库”。

## 数据

书库原文件不复制。设置、进度、会话映射与解析缓存位于 `$DSH_HOME/dsh-reader/`；书籍解析缓存以路径生成的稳定 id 加文件修改时间失效。

## 限制

EPUB 不渲染原书 CSS/图片/字体，不处理 DRM；PDF 不做像素渲染与 OCR，扫描版需要自带文本层；PDF 双栏、连字和页眉页脚可能影响文本顺序。书内检索是字面量扫描，不是全文索引。单本书默认限制 100 MB，书库扫描深度 3 层、最多 2000 个文件。
